## Additional independent catalogues

`digitraffic-webcams-catalog.json`: Fintraffic / digitraffic.fi, CC BY 4.0.
https://www.digitraffic.fi/en/terms-of-service/
Derived station metadata: only collecting stations, first active preset, geographic coordinates and public image link. Images are not included. Metadata update time is not the capture time.

`odh-webcams-catalog.json`: Open Data Hub and original providers, license and author retained per feature (`metadataLicense`, `attribution`). Only explicitly open metadata with a usable geographic position is included. Webcamurl imagery is excluded from this dataset and does not inherit the parent metadata license.
https://docs.opendatahub.com/licensing/

Separate files retain their original licenses and provenance. Combining viewport results does not relicense either catalogue or their linked imagery. Source checksums, revisions and import times are in each file.
